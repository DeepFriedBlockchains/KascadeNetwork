# Public source provenance and development

KascadeNetwork is the primary public development repository for KASCADE.

## Initial source snapshot

The public history starts at `62248169f0920277b3ee60cf275080c221a21786`,
a single independent root with 1,494 source files. Its Git tree is
`50165604d2f1d7ead1efe0b1e9a4d869ebe60753`.

The snapshot was transferred with its exact commit and tree, then published.
Subsequent development uses ordinary feature branches and pull requests.
The original source attribution remains in [NOTICE](./NOTICE).

## Bringing earlier work forward

Review selected source changes and tests before adding them to a public
feature branch. Validate the resulting public source and record its own
test results. Preserve the initial snapshot and commit new changes normally.

Publication review covers the proposed diff and its resulting public tree.
Public handoffs describe implementation status, validation evidence and
remaining work. Keep restricted review material, credentials, wallet material
and operational configuration in private channels.

## Contributions and releases

Use [CONTRIBUTING.md](./CONTRIBUTING.md) for the pull request workflow.
Maintainers control merges and releases. Publishing source is a development
milestone. Network launch and consensus activation require separate approval
and supporting validation.
