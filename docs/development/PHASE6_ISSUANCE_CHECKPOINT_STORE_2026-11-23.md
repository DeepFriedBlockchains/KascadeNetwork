# Phase 6 authenticated issuance checkpoint storage

This draft adds an uncached, versioned authority-batch row for one authenticated issuance summary. The digest binds unique reward-source claims through the ordered root and binds minted, paid and deferred totals. Stage and reopen require a caller-owned selected-chain guard for the same database and a separately trusted commitment. Invalid staging rejects the entire deferred batch. The selected-chain index hides an abandoned owner after a reorganization; a verified replacement may overwrite the summary. The focused RocksDB fixture exercises abandoned batches, an altered paid/deferred split, committed reopen, and selected-branch replacement.

Consensus still owns source acceptance. There is no separate reward ledger here. For production publication, derive the claim root and deferred balance from applied settlement, authenticate the expected digest through independently verified selected-chain evidence, pin the real virtual and selected-chain guards in the promotion recheck, and stage this row together with the ready revision in one deferred batch. The acceptance test must use a real mixed subsidy/fees/deferred settlement, remove and replace the selected branch, and verify restart and interrupted publication. The fixture uses a batch probe, so it is not an integrated pruning-readiness test. Production issuance remains disabled.
